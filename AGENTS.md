## Getting Started

This project uses NestWeaver for codebase intelligence. Run `nestweaver setup` to configure your AI tool (Claude Code, Cursor, Codex, Copilot, Gemini, etc.), then use the MCP tools below.

## Key MCP Tools

| Tool | Purpose |
|------|---------|
| `brain_context` | PPR-ranked context from seed symbols/notes — call this first for structural questions |
| `brain_search` | BM25 full-text search across code symbols, notes, headings, sections, and tags |
| `brain_impact` | Blast radius: all symbols that call/import/extend the target, grouped by depth |
| `brain_guide` | Auto-generated architecture overview of the indexed codebase |
| `detect_changes` | Risk assessment for a list of changed files |
| `investigate` | One-call orientation on a topic — returns a token-budgeted map with a bundle_id |
| `investigate_hydrate` | Fill in source bodies for investigate entries (check `body_complete` for truncation) |
| `read_symbols` | Read a symbol's source span — cheaper than reading entire files |
| `stale_check` | Compare each repo's indexed SHA against git HEAD — verify the index is current |

## When to Use

- Starting a task: call `brain_context` with task keywords as seeds
- Before modifying code: call `brain_impact` on the symbol, then `detect_changes`
- Exploring unfamiliar code: call `investigate` for broad orientation, then drill in
- Finding dead code: call `dead_code` for unreachable symbols
- Architecture overview: call `brain_guide`, or `hub_nodes` + `clusters` + `get_summary`

## Token Efficiency

- Prefer `brain_search` over `brain_context` when locating symbols or notes by name
- Use the investigate chain: `investigate` → `investigate_hydrate` → `read_symbols` (only where `body_complete` is false)
- Use `response_format: "concise"` on `brain_context` and `brain_search` for quick scans
