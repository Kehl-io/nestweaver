# Codebase Intelligence Guide

## Hard Rules

**HARD RULE:** Close your own loopholes — If your answer references a file path, read that file first. Do not cite, summarize, or reason about a file you have not opened.

**HARD RULE:** Enumerate then verify — For any "every X" / "all Y" question, run a regex/grep sweep to enumerate the full set before answering. Verify your draft answer against that sweep rather than trusting recall.

**HARD RULE:** Route project-state questions correctly — For project-state questions (status, scope, what's in a project), prefer `project_context <slug>` over `brain_search`.

**HARD RULE:** Fetch URLs before answering — For URL-bearing messages, fetch the URL before answering. Do not answer from prior knowledge of what a link probably contains.

## Architecture

Cargo workspace with 13 crates compiling to a single static binary + optional WASM module:

```
nestweaver/                     # CLI entry point (src/main.rs)
crates/
  nestweaver-schema/            # node/edge types, UIDs, confidence scoring
  nestweaver-parser/            # Tree-sitter + regex parsing for 32 languages
  nestweaver-resolver/          # cross-file import resolution with confidence scoring
  nestweaver-store/             # LadybugDB graph store, PageRank, hybrid search
  nestweaver-storage/           # pluggable snapshot storage backends (local, S3, GitLab)
  nestweaver-engine/            # indexing pipeline, query dispatch, config, snapshots
  nestweaver-algorithms/        # pure-compute graph algorithms (PPR, impact BFS) — WASM-compatible
  nestweaver-proto/             # gRPC protobuf definitions and generated Rust types
  nestweaver-daemon/            # background daemon process for persistent graph serving
  nestweaver-client/            # gRPC client for daemon communication
  nestweaver-mcp/               # MCP server (40 tools, delegates to daemon)
  nestweaver-web/               # web UI (Three.js/R3F + Axum API)
  nestweaver-wasm/              # browser-side WASM module
app/                            # macOS native app bundle (Swift launcher)
```

## Install — macOS vs Other Platforms

**macOS (recommended):** Use the native `.app` bundle for the best experience — menubar status icon, Metal GPU acceleration (~5x faster embeddings), automatic daemon lifecycle, web UI access from the menu, and crash recovery.

```bash
# Option 1: Download NestWeaver.app from GitHub Releases (recommended)
# Option 2: Build from source
cd app && bash build.sh
open target/release/NestWeaver.app
```

The app auto-detects the database, spawns the daemon with Metal GPU context, starts the web UI on port 9377, and provides a menubar icon for quick access. On quit, all child processes are cleaned up.

**All platforms (CLI):**

```bash
# npm (no Rust toolchain needed)
npm install -g @kehl-io/nestweaver

# or Cargo
cargo install --path .

# Index and query
nestweaver index
nestweaver context processPayment
nestweaver setup   # auto-configure AI tools
```

## Quick Start

```bash
# Re-index (incremental — only changed files)
nestweaver index --repo .

# Search for a symbol
nestweaver search <name>

# Get context for a function
nestweaver context <name>

# Launch the web UI
nestweaver ui
```
