## When to use NestWeaver

- **Starting a task**: Call `brain_context` with task keywords
- **Before modifying code**: Call `brain_impact` on the function
- **Exploring unfamiliar code**: Call `brain_search`
- **Working on a project**: Call `project_context`

## Tools

| Tool | Use when |
|------|----------|
| brain_context | You need structural context for a task |
| brain_search | You need to find symbols or notes |
| brain_impact | You need to check blast radius |
| brain_guide | You need an architecture overview |
| project_context | You're working on a named project |
| detect_changes | You want to assess risk of changes |
